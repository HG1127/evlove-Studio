## 运行时性能保护

V2.8 最终版实际代码包含：
- Successive Halving：先少量高价值 Cases 预筛；
- Screened Candidate 不构造完整 Artifact、不跑 Full Eval；
- Code/Package ZIP exact-path patch 优先本地 Overlay；
- Artifact Runtime `runBatch()` 共享 Source/Candidate Context；
- Population Judge 一次预筛整个 Candidate Population；
- `build-candidate` timeout 75s、单 route、无 Schema retry；
- `execute-artifact-batch` timeout 45s；
- `evaluate-population` timeout 40s；
- Batch timeout/abort 后不再自动 fan-out 重跑全部单题；
- context/payload 过大时只拆小 Batch；
- 无真实 executable screening case 时跳过预筛，避免使用 UNVERIFIED 证据错误淘汰。
