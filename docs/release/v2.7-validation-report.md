## 7. 结论

V2.7 已把代码 ZIP 的核心抽象从：

```text
Top-N files + big text context
```

升级为：

```text
Full Manifest
→ Deep Repository Index
→ AST / Symbol
→ Dependency Graph
→ Critical Modules
→ User Requirement Retrieval
→ Compact Evidence Context
```

同时明确区分：
- **Read/Parsing Coverage**
- **Execution Evidence**
- **Visual Evidence**

因此“没有 Runner”不会再被误报成“解析失败”，而“LLM digest 被截断”也不会再被误报成“项目只解析了这一小部分”。
