# V3.0 User Workflow Contract

每个用户可见主步骤必须满足以下字段：

```text
label
question
input
action
output
done
stages[]
entry
```

并且运行时必须能产生 `UserStageEvidence`：

```text
read[]      系统实际读取了什么
findings[]  当前最重要的结论
outputs[]   本步真正产生了什么
next        下一步用户应该做什么
```

约束：
1. `read[]` 必须来自 Source Artifact / Repository Intelligence / Candidate Snapshot / Eval Evidence；不得凭空生成。
2. `findings[]` 中 Problem 与 Root Cause 不得混写。
3. `outputs[]` 应尽量使用中文业务表达；技术术语只作为次级标签。
4. Deliver 阶段只能引用已验收的 Artifact Snapshot。
