# Source-qualified historical Visible failure observations

Date: 2026-10-28

Status: accepted mechanism; actual improvement, business benefit and causal transfer remain unproved.

## Actual gap

A fixed-clock replay of confirmation 21's persisted preplanning checkpoint reproduced the SHA-256 of its actual MiniMax planning request. That request had no existing Lessons, recent archive or gap advice. Starting a new confirmation Mission had not carried the prior Missions' failures into planning. This witness establishes a missing input in that run; it does not establish that all existing project-local learning paths are broken.

## Decision

An optional Mission field, `failureObservationSources`, explicitly commits up to two prior Mission/Candidate records by canonical record SHA-256, experiment ID and historical round. There is no global Mission search, implicit cross-project access or automatic classification as a Verified Skill. Legacy records omit the field and retain their existing identities and request shape.

Contracts owns strict, bounded versioned DTOs. Core extracts exact same-Visible-paper verified criterion comparisons from a unique completed rejected finalist and its stored Original comparison. Missing, partial, duplicate or unpaired measurements stay unknown; trustworthy positive comparisons accompany negative ones. Harness verifies the declared Mission and experiment, construction and snapshot commitments, execution receipt and run digest, complete frozen targets, physical readback and Original bindings. It rereads the source record after I/O to reject concurrent changes. Backend supplies storage, SHA-256 and historical execution-namespace ports.

Terminal campaigns clear the scheduler checkpoint. The explicitly declared historical round is reconstructed only to recompute the already stored cryptographic build-input binding; a wrong round fails that equality. No historical record is rewritten. Historical deployment namespace is explicit; an absent namespace means local execution rather than silently adopting the current deployment.

Only a safe projection of authorized body text and ordinary Visible comparison facts can reach planning. Both current and source Missions require existing body consent. Raw snapshots, patches, programs, style blocks, connector configuration, ordinary Hidden and independent-final records are excluded. Body completeness/binding is labelled; context is capped at 160,000 serialized characters and fails before provider I/O if it exceeds capacity. Without body consent only measured facts and provenance are available.

The independent final paper is reserved and persisted before this context is loaded. Failure to qualify a declared source pauses before planning. A server-owned `provided-to-plan` receipt records the exact declared sources and context fingerprint, is attached to each Candidate and emitted in action metadata. Model output cannot supply that receipt. It certifies input delivery to the planner, not that the model used it causally.

Historical observations are a generation treatment, not a scoring input: changing them leaves the scoring/Baseline contract stable. They are instead bound into planning revision, final-paper contract, Candidate evidence and build/recovery identities. Build, Visible, Hidden and repair admission reject a dropped, changed or misbound treatment before downstream work. Repair descendants preserve the parent receipt and restart normal validation. No acceptance threshold, repair budget, window, model fallback or final-paper retry is added.

## Verification and limits

Tests cover absent/default sources, false or changed commitments, duplicate/self sources, wrong round, incomplete or mismatched execution and files, concurrent mutation, separate consent, phase isolation, safe model egress and Candidate binding. The actual sealed C21 repaired file and its stored execution qualified in a read-only context preview: paired scores were 95→94, 96→89 and 94→90; five other criteria remained unpaired. The real router's transport was intercepted, with zero real model calls, isolated executions or remote writes. This establishes the source-to-context mechanism only.

A later preregistered with/without-memory experiment on unseen tasks is still needed to establish causal transfer. A new same-SOP trial must independently pass every unchanged gate. Real human/business observations and actual cost evidence are still required for benefit. Historical failures, expired budgets and independent final papers remain preserved.

The final verification covers 510 distinct related tests across 29 files, all 11 Runner tests, architecture checks, changed-file lint and the full TypeScript/production build. The final broad run had one new test-fixture error (missing existing experiment-design entries); its focused rerun passes both contract tests without changing runtime or weakening the schema. Historical C17–C21 canonical hashes remain identical. With identical local authorization settings, the default planner/router replay still exactly matches the actual C21 request-body hash. These engineering checks do not replace a new real model experiment.
