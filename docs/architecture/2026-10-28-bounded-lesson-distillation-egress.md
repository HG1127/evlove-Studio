Date: 2026-10-28

Status: accepted for the server Workflow; actual accepted-SOP learning and causal transfer remain unproved.

## Observed problem

The server Workflow serialized the complete winning Candidate and Validation into `distill`. A local synthetic interception of that actual AST-selected composition and production AI router showed executable script/style sentinels and independent-final questions in the provider request. It made zero external requests and used no actual SOP or final question. This proves the composition defect, not an actual disclosure. Confirmation 20 was cancelled before planning/learning; its actual usage ledger contains zero distill requests. Its cancelled outcome and unused budget remain closed.

## Decision

- Contracts owns a strict `lesson-distillation-context-v1` egress DTO. Harness constructs it using injected hash/readback ports; backend composition supplies existing frozen-Artifact verification. No concrete Storage/HTTP implementation enters Harness.
- The builder keeps the existing accepted-offline/live-Release eligibility, exact Candidate/Validation source and current evidence fingerprint. Offline input requires unique complete target snapshots and verified frozen bytes; missing/mismatched receipts fail before AI. Text-snapshot hashes and physical Artifact hashes remain distinct for native Office/table/package formats.
- HTML context contains readable body text, retaining displayed code examples while excluding executable script/style/template/head content and attributes. Non-HTML snapshot representations remain available. Original parsed text is labelled as bound only when its digest matches the locked Original; an incomplete HTML index is omitted without raw fallback.
- Per-artifact retrieval and combined budgets are explicit; `availableChars` and `complete` describe the available text projection, not unobserved bytes or runtime behavior. The whole serialized DTO has a 256,000-character ceiling; an oversized payload fails before transmission.
- Learning receives ordinary Hidden document observations bound to the accepted physical hashes, narrowed numeric native observations, ordinary evaluation and sanitized Release/freshness/trend. It receives no raw runs, traces, snapshots, patches, connector configuration or independent-final suite, execution, score or feedback.
- The AI gateway validates this version before provider selection/transport. Unsafe unversioned server `distill` callers now fail closed and must migrate to the explicit builder. There is deliberately no legacy raw-object fallback. The sole server Workflow caller is migrated in this change; unrelated local/browser compatibility paths are not rewritten.
- Existing output validation, Lesson provenance, offline downgrade and production learning governance are preserved. This input boundary cannot itself award a Verified Skill or establish causal transfer.

## Verification and limits

Synthetic tests exercise the actual server builder with frozen-byte reads and the real gateway with an intercepted provider transport, reject forbidden nested objects before fetch, preserve body/hash evidence and prove immutable inputs. Harness checks include unreadable/changed/duplicate sources, stale validation, missing body boundaries, incomplete retrieval, bound native reports and eight non-HTML representations. The native-format fixtures establish context compatibility only, not real Office execution.

Historical failures and spent final papers are unchanged. A read-only counterfactual projection of a failed historical Candidate is a context/budget check only; it must never be stored or described as acceptance, a distilled Lesson, real user benefit, actual billing or unseen-task transfer.
