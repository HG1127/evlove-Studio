# Bound source fragment selections

Status: prospective opt-in implementation. Fresh qualification and the full C42 acceptance remain required.

The first marker-template calibration ended unqualified on its sixth response. Markers and source identities were correct, but one generated 71-character quote was absent from both complete measured bodies. That result is retained as a failure. It is neither corrected nor replayed as a passing assessment.

The next protocol makes literal text runtime-owned. A complete measured body is partitioned into contiguous UTF-16 ranges without trimming, normalization or dropped whitespace. The initial segmenter prefers newline boundaries within 800 code units, below the existing 4,000-unit quotation limit, and never splits an existing surrogate pair. Contextual spans avoid attaching an ID to every short source line. An opaque selection ID binds logical source ID, original Artifact SHA, UTF-8 body SHA256, range and segmentation version. Source identities are not merged merely because their text matches. Repeated observations of the same source may share a dictionary entry.

The distinct `paired-judge-input-v2-source-fragments` wire moves complete bodies into that dictionary while retaining every observation attribute, prefix/suffix, native fact, case, file declaration and slot mapping. Each slot carries its original observation count and a canonical JSON digest of the complete original observation packet. A mechanical restoration validates those bindings, dictionary hashes and exact range coverage; the factory also compares the restored full input with its original before returning. These unkeyed digests detect inconsistency in the issued projection, not malicious replacement of both data and digests: the frozen request and route remain the external identity anchors. This is a projection of measured text, not a claim to reconstruct original HTML bytes or a new physical observation.

Under a separate JSONL header and scoring-route identity, the model returns raw `sourceSelections` and explicit note markers. It never supplies quotation text or ownership hashes. A present selection must belong to that slot; an absence selection must belong to the comparison source and is checked with an exact, unnormalized search against the complete subject body. The existing normalized literal/marker checks still apply after deterministic resolution. This extra exact check prevents a composing Unicode mark from being misclassified as absent. A supported citation is not proof of semantic relevance, sufficient inference or overall Safety.

The new raw-selection DTO is journaled before resolution. Its raw result hash and manifest hash remain separate from derived-quotation and rendered-note hashes. Recovery reconstructs the same issued manifest and reruns selection, ownership, absence and marker validation. Old observation versions remain strictly readable under their original protocols; old failures do not become selections implicitly. No score, verdict, criterion, private label, frozen paper, budget or prior result is changed by the new representation.
