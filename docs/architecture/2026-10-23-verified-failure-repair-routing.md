# Verified failure routing and frozen repair validation

An ordinary Hidden assessment may contain both a verified rejection and a criterion with incomplete evidence. The rejection is actionable without converting the incomplete criterion into a product failure or success. Gate F retains its unverified overall state, checks the physical frozen files, and may target only the verified failed criteria. An otherwise undecided assessment still waits for evidence. Missing physical files, changed bindings, duplicate results, and independent final-paper rejection never authorize this repair shortcut.

For Artifact targets, a complete stored rejection on the same contract, physical Original/Candidate binding, measured-review version, execution policy, and answer-sheet fingerprint can resume toward repair after the observation freshness window. Both independent assessments must be complete. This retains the existing negative verdict; it does not reroll a Judge, refresh the observation time, or supply fresh passing/production evidence. Passing observations retain the existing freshness rules.

The Workflow processes a frozen Experiment or bound failed Validation checkpoint before refreshing the preparatory Visible baseline. Holdout and Gate F still perform their own identity checks. HTTP/connector targets are excluded. A changed scoring contract or model route is still blocked before checkpoint routing.

A targeted repair receives a new Candidate identity and frozen files, remains without a Visible winner, and returns to the existing Plan-to-Experiment boundary. Experiment verifies and measures those exact files on the complete Visible suite before ordinary Hidden can run again. It records normal build/execution checkpoints for outages and never rebuilds an unavailable frozen repair. The independent final paper stays reserved and unchanged.

This keeps contracts → core → harness → adapters/apps unchanged. Pure routing and injected execution remain in Harness; physical reads remain in adapters/composition roots. It does not claim that the real pilot's content, interaction protection, independent final, delivery, business benefit, or learning-transfer gates have passed.
