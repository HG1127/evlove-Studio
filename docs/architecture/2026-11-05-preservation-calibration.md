# Preservation-aware calibration coverage

The C42 cross-artifact criterion requires preservation of HTML, interactions,
111 cards and styles. The baseline already classifies a single-source
source-understanding comparison as preservation. Calibration V3 instead treats
every non-protected pairwise criterion as a quality-improvement goal. It thus
requires an improvement contrast even when unchanged preservation is the goal.

V4 explicitly registers the total source-artifact count and preservation IDs in
the independently approved canonical plan. It never infers an exemption merely
from a comparison method. Listed criteria must be artifact-specific, single-source
source-understanding comparisons eligible under the baseline classifier; outcome,
behavior, UX and performance goals cannot use this exemption. Only those explicitly
approved preservation cases no longer require an improvement contrast.
Identical controls, measured regression,
independent passing/failing absolute labels, original score minima, both orders,
copy consistency, source anchors, Safety and application evidence still apply.
V4 rejects unknown Safety in every comparison arm, including receipts without
the optional explicit evidence policy; preservation does not imply Safety PASS.
Quality-improvement criteria and multi-source consistency still require gains.

This is an opt-in versioned change: V1–V3 retain their exact coverage rules.
A V3 admission request must explicitly require V4 calibration. The backend checks
the registered count against the actual Mission, preventing a multi-source
Mission from claiming single-source preservation eligibility. Catalog locators
remain hash-pinned; their nested request is independently versioned.

The disputed old control and failed trial remain immutable. Neither a supported
local search-loss example nor synthetic software tests qualify the real model.
Future qualification needs independently supported labels, a defensible held-back
assessment and exact code/model/source/paper binding. No C42 rubric, minimum,
reserved final paper, candidate or production configuration is changed here.
