# Preserve valid zero-score paired verdicts

The paired protocol declares integer scores from 0 through 100. Its shared legacy evaluator parser nevertheless rejected any arm whose accuracy, evidence and riskCoverage were all zero. A frozen synthetic complete negative on `267f1b3` demonstrates the consequence in the actual gateway: JSON-object output spends the one format correction on the same valid negative, then aborts; JSONL rejects it as invalid transport after the first order. Neither path records the two-order product failure.

The common evaluator shape now validates identities separately from the legacy all-zero heuristic. Unpaired callers retain that compatibility behavior. Paired JSON-object and JSONL responses retain valid zeros, negative flags and Safety FAIL as data. Range, unique identities, issued criterion/case mapping, request echo, complete three-slot coverage and two-order/copy checks remain in force. A structurally valid low score is not a format error; semantic correctness and missing evidence still need independent qualification. Accepting a response does not certify its truth or make it a passing artifact.

`issued-paired-generation-schema-v2-valid-zero` is included in the existing scoring-route fingerprint. Fresh requests therefore bind the changed parser and guidance; prior invalid responses, ended windows, claims and verdicts are not reopened or rescored. No retry budget is expanded. Both gateway transports must preserve the frozen zero-score negative through settlement as verified score 0, pass false and Safety FAIL, with Winner blocked and exactly one mock request per order. This is synthetic boundary verification, not real model calibration, SOP improvement, business benefit or causal transfer.
